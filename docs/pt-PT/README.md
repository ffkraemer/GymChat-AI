# Documentação GymChat AI

## Visão Geral

Bem-vindo à documentação oficial do GymChat AI.

O GymChat AI é uma plataforma de relacionamento e fidelização para ginásios baseada em WhatsApp e Inteligência Artificial (Gemini, OpenAI, ou Azure OpenAI, de forma intercambiável).
